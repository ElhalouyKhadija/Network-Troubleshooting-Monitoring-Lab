# Network Troubleshooting & Monitoring Lab

## Overview

A practical networking lab focused on troubleshooting, connectivity testing, DNS resolution, TCP port testing, firewall inspection, and TCP connection monitoring.

The lab was performed on both **Windows** and **Kali Linux** using native command-line networking tools.

## Objectives

* Understand basic network configuration and routing.
* Test local and Internet connectivity.
* Verify DNS resolution.
* Test TCP connectivity on different ports.
* Inspect firewall configurations.
* Monitor TCP listening ports and active connections.
* Practice troubleshooting using command-line tools.

## Phases

### Phase 1 – Basic Network Connectivity

Tested:

* IP/network connectivity
* Local gateway connectivity
* DNS-based connectivity
* Network path tracing
* HTTP connectivity

Performed on Windows and Kali Linux.

### Phase 2 – IP Configuration, Routing and DNS Resolution

Inspected:

* IP configuration
* Default routes
* DNS configuration
* Domain resolution
* Basic TCP connectivity

Performed on Windows and Kali Linux.

### Phase 3 – TCP Port Connectivity Testing

Tested TCP connectivity to:

* Port `443` – HTTPS
* Port `80` – HTTP
* Port `22` – SSH

Results were compared between Windows and Kali Linux.

### Phase 4 – Firewall Inspection

Inspected firewall and packet-filtering configuration.

**Windows:**

* Firewall profiles
* Enabled firewall rules

**Kali Linux:**

* UFW availability
* `nftables` rules
* `iptables` policies and rules

### Phase 5 – TCP Connection Monitoring

Inspected:

* Listening TCP ports
* Established TCP connections
* TCP socket states
* Associated processes where available

Performed on Windows and Kali Linux.

### Phase 6 – Documentation and Final Check

Reviewed, organized, and documented the complete Network Troubleshooting & Monitoring Lab.

The final review covered:

* Network configuration and connectivity
* IP addressing and routing
* DNS troubleshooting
* TCP connectivity and port testing
* Firewall inspection
* TCP connection monitoring
* Windows and Kali Linux troubleshooting
* Technical documentation and project organization
