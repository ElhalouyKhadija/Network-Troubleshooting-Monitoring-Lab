# Phase 6 — Documentation and Final Check

## Objective

The purpose of this phase was to review, organize, and document the complete Network Troubleshooting & Monitoring Lab.

The project was performed using both **Windows** and **Kali Linux** and documented through practical network commands, observed results, troubleshooting tests, and supporting screenshots collected during the lab.

## Final Network Check

The final review covered the following key areas:

* Network configuration and IP addressing
* Default gateway and routing
* DNS resolution and connectivity
* Local and Internet connectivity testing
* Network path tracing
* TCP connectivity and port testing
* Firewall inspection
* TCP connection and socket monitoring
* Windows and Kali Linux network troubleshooting

These areas correspond to the practical work documented across the five completed phases.

## Documentation
